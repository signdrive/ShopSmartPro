# ShopSmart Pro - Browser Extension

ShopSmart Pro is a powerful browser extension that enhances your online shopping experience with advanced search capabilities, deal tracking, price monitoring, and productivity features.

## ✨ Features

- **Smart Search**: Advanced search across multiple shopping categories
- **Price Tracking**: Automatic price drop notifications and alerts
- **Deal Browser**: Discover current flash deals and limited-time offers
- **Product Comparison**: Side-by-side product comparison with feature analysis
- **Voice Search**: Hands-free search capability
- **Multi-platform Support**: Works with various shopping websites

## 🚀 Installation

1. Download the extension from the browser store
2. Click "Add to Browser" when prompted
3. Pin the extension to your toolbar for easy access
4. Start using the right-click context menu for quick searches

## ⚙️ Usage

### Basic Search
1. Click the ShopSmart Pro icon in your toolbar
2. Enter your search query
3. Select preferred categories
4. Press Enter or click Search

### Price Tracking
1. Find a product you want to track
2. Click the "Track Price" button
3. Receive notifications when the price drops

### Product Comparison
1. Right-click on products and select "Compare"
2. View products side-by-side
3. Compare features and prices

## 🔧 Configuration

Access settings by:
1. Clicking the extension icon
2. Selecting "Settings"
3. Configuring your preferences:
   - Default country/site preference
   - Notification settings
   - Search preferences
